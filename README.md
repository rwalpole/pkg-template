# Personal Knowledge Graph Template

This repository contains a Personal Knowledge Graph (PKG) template file [pkg.ttl](pkg.ttl) created for a tutorial session at [XML Summer School](https://xmlsummerschool.org/) 2026.

In adddition to the template, a number of useful ontology files have been added in Turtle RDF format in the [ontology](ontology) directory and some SHACL shapes in the [shacl](shacl) directory.
